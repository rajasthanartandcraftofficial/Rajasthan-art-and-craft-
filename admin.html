Manage your collection

This page is the management interface for the next database connection. Product and price editing can be connected to Supabase so changes become visible to every customer. For security, no password or secret key is stored in this website.

  • Mark products featured / active

  • Secure email/password login through Supabase

The public website works independently with its built-in catalogue. Connect the database before using this page for real business management.
